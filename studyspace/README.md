# StudySpace — Student Productivity Dashboard

StudySpace is a student productivity dashboard built using React. It helps students organize their daily tasks, monitor their progress, and manage study sessions through a clean and interactive interface.

## Features

- **Task Management:** Add and delete tasks easily.
- **Task Completion Tracking:** Mark tasks as completed or pending.
- **Task Filtering:** Filter tasks by All, Pending, and Completed status.
- **Focus Timer:** Use a timer to organize focused study sessions.
- **Daily Goals:** View daily study goals and progress.
- **Progress Overview:** View task statistics through dashboard cards.
- **Local Data Persistence:** Save tasks in browser localStorage so they remain available after refreshing the page.
- **Responsive Interface:** Use the dashboard across different screen sizes.

## Tech Stack

- **React** — Component-based user interface
- **JavaScript** — Application logic and interactivity
- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **Vite** — Development server and build tool
- **localStorage** — Browser-based task persistence

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/samruddhikulkarni467-ux/studyspace.git
   ```

2. Navigate to the project directory:

   ```bash
   cd studyspace
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## React Concepts Used

- **Components and JSX:** Structure the dashboard into reusable UI sections.
- **useState:** Manage tasks, filters, and interactive UI state.
- **useEffect:** Synchronize task data with localStorage.
- **Event Handling:** Handle user actions such as adding, deleting, and completing tasks.
- **Dynamic Rendering:** Display task lists based on application state.
- **Array Methods:** Use methods such as `map()` and `filter()` to render and filter tasks.

## Project Objective

The objective of StudySpace is to bring essential student productivity tools into one dashboard, making it easier to organize academic tasks and maintain a consistent study routine.

## Future Improvements

- User authentication and personalized dashboards
- Backend integration and cloud-based data storage
- Subject-wise and weekly progress analytics
- Study reminders and notifications
- Customizable study sessions

## Current Limitations

StudySpace is currently a frontend application. Task data is stored locally in the browser and is not automatically synchronized between devices or users.
